# ProcureMind

سامانه هوشمند مدیریت بازرگانی و تدارکات با رابط چت‌محور.
سند مبنا: [`docs/ProcureMind_Development_Guidelines.md`](docs/ProcureMind_Development_Guidelines.md)

## وضعیت فعلی: فاز صفر و یک (نمونه اولیه تست مدل‌ها)

یک چت ساده فارسی + OCR برای آزمایش مدل‌ها روی سخت‌افزار واقعی. **هنوز دیتابیس و ماژول کسب‌وکار ندارد** (طبق دستورالعمل).

| بخش | کار |
|---|---|
| چت | گفت‌وگوی استریم با Qwen، نمایش زمان، توکن بر ثانیه و مصرف RAM/CPU |
| OCR | آپلود تصویر یا PDF (حداکثر ۱۰ صفحه)، نمایش پیشرفت هر صفحه، متن قابل ویرایش |
| تحلیل | ارسال متن اصلاح‌شده به Qwen (خلاصه، یا استخراج JSON پیش‌فاکتور/درخواست خرید) |
| لاگ | هر درخواست در `logs/tests.jsonl` ثبت می‌شود؛ فایل‌های آپلودی اصلی در `data/uploads/` |

## نصب روی ویندوز

پیش‌نیاز: Python 3.10 به بالا (با تیک Add to PATH) و اینترنت برای نصب اولیه.

1. مخزن را clone کنید.
2. `powershell -ExecutionPolicy Bypass -File scripts\setup_windows.ps1`
   (محیط `.venv`، وابستگی‌ها و آخرین llama.cpp نسخه CPU را نصب می‌کند)
3. **هر تعداد مدل (`.gguf`) را در پوشه `models\` بگذارید.** نام فایل mmproj باید کلمه `mmproj` را داشته باشد؛ مدل‌های OCR با `dots` یا `ocr` در نام شناخته می‌شوند و بقیه مدل چت حساب می‌شوند. زیرپوشه‌ها هم پشتیبانی می‌شوند.
4. فونت SG Kara همراه مخزن است (`frontend\fonts\`).
5. اجرا: فقط `scripts\start_app.bat` ← سپس <http://127.0.0.1:8000>
6. در صفحه روی **«⚙ مدل‌ها و تنظیمات»** بزنید تا مدل OCR (Dots + mmproj) را انتخاب کنید. **مدل چت** را مستقیم از نوار پایین چت انتخاب و «بارگذاری» کنید. برنامه خودش `llama-server` را بالا می‌آورد، زمان بارگذاری را نشان می‌دهد و در `logs\tests.jsonl` ثبت می‌کند. به‌صورت پیش‌فرض با بارگذاری یکی، دیگری خاموش می‌شود تا RAM پر نشود.

> `start_qwen.bat` و `start_ocr.bat` دیگر لازم نیستند (فقط برای اجرای دستی). اگر آن‌ها را باز گذاشته باشید، صفحه پیام می‌دهد که روی پورت سرور دیگری در حال اجراست.

## استفاده: چت با پیوست فایل

- پیام را بنویسید و Enter بزنید؛ یا با دکمه **«+»** تصویر یا PDF پیوست کنید (مثل چت‌های معمول).
- لیست **«خواندن فایل»** روش استخراج متن را تعیین می‌کند:
  - **لایه متنی PDF** (پیش‌فرض برای PDF دیجیتال): فوری و دقیق، بدون OCR. اگر فایل لایه متنی نداشته باشد، برنامه خودش روش «دستی» را پیشنهاد می‌کند.
  - **دستی**: متن را خودتان (مثلاً با Google Lens) در کادر می‌چسبانید؛ فایل اصلی در `data\uploads` ذخیره می‌شود.
  - **Dots OCR** (کند) و **PaddleOCR** (سریع، فارسی ضعیف): نیاز به مدل/بسته مربوطه.
- متن استخراج‌شده در یک **کارت قابل ویرایش** داخل چت می‌آید. می‌توانید آن را اصلاح و با دکمه «نرمال‌سازی متن» استانداردسازی کنید و نوع تحلیل را (پرسش من، خلاصه، JSON پیش‌فاکتور، JSON درخواست خرید) بزنید و «ارسال به مدل» را بزنید.
- گزینه «تحلیل خودکار بعد از استخراج» برای لایه متنی PDF پیش‌فرض روشن است (پیام شما همراه متن به مدل می‌رود)؛ برای OCR و دستی خاموش است تا اول متن را مرور کنید.
- زیر پاسخ JSON پیش‌فاکتور، حساب‌ها خودکار بررسی می‌شوند (تعداد × فی، جمع ردیف‌ها، مالیات).

### PDF
- پیش‌فرض فقط **صفحه ۱** پردازش می‌شود (فیلد «صفحه‌ها»: مثلاً `2-4` یا `1,3` یا `all`، حداکثر ۱۰ صفحه). هر صفحه اسکن‌شده روی CPU چند دقیقه OCR می‌خواهد.
- لایه متنی به روش «مرتب‌شده» خوانده می‌شود: حروف شکل‌های نمایشی (ﺗﺎﯾﯿﺪ) به حروف استاندارد (تایید) تبدیل می‌شوند، ردیف‌ها بر اساس مکان روی صفحه بازسازی و کلمات راست‌به‌چپ مرتب می‌شوند و ستون‌های جدول با `|` جدا می‌شوند. اگر نتیجه عجیب بود، «لایه متنی: خام» را برای مقایسه انتخاب کنید.

نقطه‌های سبز بالای صفحه نشان می‌دهند هر مدل بالا آمده است.

## موتور سوم: PaddleOCR (اختیاری، سریع)

موتور OCR کلاسیک و سبک که روی CPU معمولاً در چند ثانیه جواب می‌دهد. در لیست «خواندن فایل» پایین چت انتخابش می‌کنید؛ زبان (فارسی `fa`) در «⚙ مدل‌ها و تنظیمات» است. برای مقایسه، یک فایل را با چند روش جدا بفرستید؛ هر نتیجه یک کارت جدا می‌شود.

نصب (داخل همان `.venv`):
```
pip install -r backend\requirements-paddle.txt
```
- بار اول مدل‌ها از اینترنت دانلود می‌شوند.
- برای فارسی از مدل عربی استفاده می‌شود؛ دقت روی فارسی تست نشده است.
- فقط متن خط‌به‌خط می‌دهد (ساختار جدول و فیلدها را نمی‌فهمد).
- اگر خطای oneDNN/mkldnn دیدید، همین حالت پیش‌فرض (خاموش) است؛ برای روشن‌کردنش `PADDLE_MKLDNN=1`.

## نکات سخت‌افزار (۱۶ گیگ RAM، بدون GPU)

- Qwen 9B و Dots OCR با هم حدود ۱۰ تا ۱۱ گیگ RAM می‌گیرند (تخمین؛ باید اندازه‌گیری شود). اگر RAM پر شد، **هر بار فقط یکی را اجرا کنید**.
- سرعت Qwen 9B روی CPU کند است (چند توکن در ثانیه). همین عدد را در نتایج ثبت کنید.
- OCR با ctx=8192 اجرا می‌شود؛ مقدار پیشنهادی مدل ۱۳۱۰۷۲ است ولی RAM زیادی می‌خواهد.

## سازگاری مدل‌ها (باید تست شود)

Dots OCR فقط با نسخه‌ای از llama.cpp کار می‌کند که پروژکتور `dots_ocr` را دارد (طبق صفحه‌های مدل، build شماره b8731 به بعد). اگر `start_ocr.bat` خطای معماری یا mmproj داد، llama.cpp را به‌روز کنید یا fork ذکرشده در صفحه مدل را امتحان کنید. نتیجه را در `docs/AI_OCR_TESTS.md` بنویسید.

## تست بدون مدل واقعی

```
python -m uvicorn tests.mock_llama:app --port 18080
python -m uvicorn tests.mock_llama:app --port 18081
set QWEN_URL=http://127.0.0.1:18080 & set OCR_URL=http://127.0.0.1:18081
python -m uvicorn backend.main:app --port 8000
python tests\smoke_test.py
```
