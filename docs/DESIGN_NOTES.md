# یادداشت‌های طراحی رابط نهایی

وضعیت: **نمونه‌ی طراحی اول ساخته شد و منتظر نظر مالک است** (تأیید نشده). رابط فعلی (`frontend/index.html`) فقط ابزار آزمایش است.

## جهت طراحی نمونه‌ی اول
- صفحه‌ی چت راست‌به‌چپ، سایدبار گفتگوها در سمت راست، نوار بالای صفحه با وضعیت مدل چت، ستون گفتگو (حداکثر ۷۸۰px) و کادر پیام شناور در پایین با «+» برای پیوست.
- زیر کادر پیام: انتخاب مدل چت و روش خواندن فایل.
- پیام دستیار با لحن گرم؛ کارت «نوع سند» (برچسب، اطمینان، شواهد)، جدول اقلام با نتیجه‌ی بررسی حساب، و کارت **پیشنهاد اقدام** (مثلاً «فروشنده در بانک فروشندگان نیست؛ ثبت شود؟») با دکمه‌های تأیید/ویرایش. جمله‌ی ثابت: «هیچ چیزی بدون تأیید شما ثبت نمی‌شود.»
- انیمیشن: ورود نرم پیام‌ها (fade + بالا آمدن)، نقطه‌های «در حال نوشتن»، بالا آمدن ملایم دکمه‌ها هنگام hover.

## توکن‌های ظاهری (نسخه‌ی دوم: رنگ‌بندی شادتر)
| نقش | مقدار |
|---|---|
| زمینه‌ی اصلی / سایدبار | `#F7F8FF` / `#EEF0FF` |
| متن اصلی / کم‌رنگ | `#1B1F3B` / `#5A6080` |
| خط‌ها | `#E0E3F7`، `#ECEEFB` |
| رنگ اصلی (ایندیگو) / زمینه‌ی ملایم / متن روی آن | `#4F46E5` / `#E8E7FF` / `#3730A3` |
| پیشنهاد اقدام (نارنجی ملایم) | متن `#9A3412`، زمینه `#FFF1E3`، خط `#FDD0A2` |
| تأیید (سبز) | متن `#166534`، زمینه `#E6F7EE` |
| گوشه‌ها | کارت ۱۶px، دکمه ۱۰px، کادر پیام ۲۰px |
| اندازه‌ی دکمه‌ها | ۳۴ تا ۳۶px ارتفاع (کوچک‌تر از نسخه‌ی اول) |

## تغییرات نسخه‌ی دوم (به درخواست مالک)
- سایدبار قابل جمع‌شدن (فقط آیکون‌ها)؛ مدل چت فقط یک‌بار (نوار پایین چت) نشان داده می‌شود؛ هدر بالا برای افزودن‌های بعدی (مشخصات کاربر، تم برنامه، …) نگه داشته شد؛ متن‌ها کوتاه شدند.

فونت: SG Kara (محلی، woff2) در پیاده‌سازی نهایی؛ نمونه‌ی طراحی به‌خاطر محدودیت پیش‌نمایش از Vazirmatn استفاده کرد. ارقام نمایشی فارسی.

## هنوز تصمیم‌گیری نشده
حالت تیره، چیدمان موبایل، صفحه‌ی ورود، صفحه‌ی فروشندگان و پیش‌فاکتورها، رنگ برند دقیق، لوگو.
