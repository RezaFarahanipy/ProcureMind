# نسخه‌بندی

نسخه‌بندی معنایی `MAJOR.MINOR.PATCH` (مثل `0.1.0`)؛ منبع یگانه: فایل `VERSION` در ریشه‌ی مخزن.

| بخش | چه زمانی بالا می‌رود |
|---|---|
| `PATCH` | رفع اشکال و تغییر کوچک بدون قابلیت تازه |
| `MINOR` | قابلیت تازه یا پایان یک فاز/ماژول تأییدشده (مثلاً 0.2.0 = پایان فاز ۱ + هسته‌ی فاز ۲) |
| `MAJOR` | از 1.0.0 به بعد: تغییر ناسازگار با داده‌ها/رابط. تا پایان فازهای اصلی `0.x` می‌ماند |

## روش انتشار
```
python scripts\release.py minor          # VERSION + CHANGELOG + commit + tag vX.Y.Z
python scripts\release.py patch --push   # با ارسال commit و tag به گیت‌هاب
```
قبل از آن: همه‌ی تغییرات commit شده باشد و `CHANGELOG.md` را تکمیل کنید. تغییر ساختار دیتابیس همیشه با Migration و `MINOR` یا بالاتر.

## نمایش در برنامه
`/api/version` نسخه، commit و تاریخ را می‌دهد. رابط فعلی آن را در هدر نشان می‌دهد؛ رابط نهایی در پایین سایدبار.
