# فونت SG Kara

مالک محصول تأیید کرده فونت دارای مجوز و رایگان است؛ فایل‌های woff2 داخل مخزن هستند:

- `SGKara-FaNum-{Light,Regular,SemiBold,Bold}.woff2` — ارقام فارسی (فونت اصلی رابط)
- `SGKara-Std-{Light,Regular,SemiBold,Bold}.woff2` — ارقام لاتین (فیلدهای فنی)

اگر فایل‌ها نباشند، رابط با Tahoma / system-ui کار می‌کند.
